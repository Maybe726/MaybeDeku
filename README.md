# 坦克大战 Tank Battle

经典 Battle City（坦克大战）风格的 HTML5 网页游戏，纯 Canvas + 原生 JavaScript 实现，**零依赖、零构建、零外部资源**，打开 `index.html` 即玩。

## 在线试玩

GitHub Pages：https://maybe726.github.io/MaybeDeku/

（在仓库 Settings → Pages 中将 Source 设为 `main` 分支根目录即可开启。）

## 本地运行

直接用浏览器打开 `index.html` 即可；或起一个本地服务器：

```bash
# 任选其一
npx serve .
python -m http.server 8000
```

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始游戏 / 返回菜单 |

## 玩法规则

- 消灭关卡中的所有敌方坦克即可过关，共 **3 关**，难度递增。
- 保护地图底部的**金色基地（金鹰）**，基地被摧毁立即失败。
- 生命耗尽同样失败；最高分保存在本地浏览器。
- 敌方坦克分三种：普通（灰）、快速（青）、重型（红，3 点血量）。
- 击毁携带道具的坦克（出生时高亮）可掉落随机道具：
  - ★ 火力升级（可叠加两级：双发 → 穿钢炮弹 + 提速）
  - ⛨ 无敌护盾
  - ♥ 额外生命
  - ✦ 全屏轰炸

## 地形说明

- 🟥 砖墙：可被炮弹摧毁
- ⬜ 钢墙：普通炮弹打不穿，需要 2 级炮弹
- 🟦 水域：坦克无法通过，炮弹可以飞过

## 技术要点

- 单文件游戏逻辑 `game.js`（约 600 行），无任何第三方库
- 基于 `requestAnimationFrame` 的游戏主循环，dt 帧时间步进
- 网格地图 + AABB 碰撞检测（坦克-地形、坦克-坦克、子弹-子弹对撞）
- 敌方坦克 AI：随机巡游 + 玩家/基地对齐射击
- WebAudio API 实时合成音效，无音频文件
- Canvas 程序化绘制所有图形（坦克、砖墙、爆炸粒子特效等）

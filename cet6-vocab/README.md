# 六级词汇通 · CET-6 Vocabulary

一个纯前端（HTML + CSS + 原生 JS）的英语六级核心词汇学习与备考网站，无需构建、无需后端，打开 `index.html` 即可使用。学习数据保存在浏览器 localStorage 中。

## 功能

| 模块 | 说明 |
| --- | --- |
| 📚 词汇 | 722 个六级核心重点词（音标、释义、真题风格例句），支持中英文搜索、按首字母筛选、朗读发音、标记掌握 |
| 🃏 闪卡 | 卡片翻面记忆，支持全部乱序 / 仅未掌握 / 随机 50 词三种范围，认识/不认识标记同步到词库 |
| ✏️ 测验 | 三种题型：英译汉选释义、汉译英选单词、看释义拼写单词，自动判分并回顾错题 |
| 📝 真题 | 选词填空 3 套（题材与难度参照六级真题 Section A，每套 15 词选 10 填空）+ 语境辨词单选（从词库例句随机生成，每次 10 题） |
| 📊 统计 | 掌握进度、测验次数、平均正确率、测验历史记录，支持一键清空数据 |

## 本地运行

直接用浏览器打开 `index.html` 即可；或启动一个静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 把代码推送到 GitHub 仓库
2. 仓库 Settings → Pages → Source 选择 `main` 分支根目录
3. 几分钟后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 目录结构

```
├── index.html        # 主页面
├── css/style.css     # 样式
├── js/app.js         # 全部交互逻辑
├── js/data-1~4.js    # 核心词汇数据（722 词）
└── js/exam-data.js   # 选词填空题库（3 套仿真题）
```
